## 🔐 SESSION & COOKIE SYSTEM

### Session Duration
- **30 days** persistent
- **Server-side** storage
- **Activity tracking** enabled
- **Automatic timeout** after 30 days

### Cookies Set
| Cookie Name | Value | Lifetime |
|---|---|---|
| `user_id` | MD5 hash | 30 days |
| `user_email` | User email | 30 days |
| `user_name` | User name | 30 days |
| `logged_in` | '1' | 30 days |
| `PHPSESSID` | Session ID | 30 days |

### Session Data Stored
```php
$_SESSION['user_id']        // Unique identifier
$_SESSION['user_name']      // Full name
$_SESSION['user_email']     // Email
$_SESSION['logged_in']      // Boolean
$_SESSION['login_time']     // When logged in
$_SESSION['last_activity']  // Activity tracking
$_SESSION['ip_address']     // Security validation
$_SESSION['user_agent']     // Browser tracking
```

#### Access User Data

## 🎓 EXAMPLES

### Example 1: Check if User is Logged In
```php
<?php
include_once 'sign/check_session.php';

if (isset($_SESSION['logged_in']) && $_SESSION['logged_in'] === true) {
    echo "Welcome " . $_SESSION['user_name'];
} else {
    echo "Please login first";
}
?>
```

### Example 2: Add Your Own Protected Page
```php
<?php
// At the very top of your page
include_once 'sign/check_session.php';

// From here on, you can assume user is logged in
// User is either authenticated or redirected to login

// Now you can use session data
$username = $_SESSION['user_name'];
$email = $_SESSION['user_email'];
?>
<!DOCTYPE html>
<html>
<head>
    <title>My Protected Page</title>
</head>
<body>
    <h1>Welcome, <?php echo $username; ?></h1>
    <p>Email: <?php echo $email; ?></p>
</body>
</html>
```

### Example 3: Load User Stats with AJAX
```javascript
async function loadStats() {
    try {
        const response = await fetch('api/user_profile.php?action=get_stats');
        const data = await response.json();
        
        if (data.success) {
            console.log(data.stats.quizzes_completed);
            console.log(data.stats.points_earned);
        }
    } catch (error) {
        console.error('Error loading stats:', error);
    }
}

loadStats();
```

## 🛠️ CUSTOMIZATION

### Change Cookie Lifetime

Edit these files and change `2592000` (seconds):

**For 7 days**: `604800`
**For 14 days**: `1209600`
**For 30 days**: `2592000`
**For 1 year**: `31536000`

Files to edit:
- `sign/check_session.php` (line 2)
- `sign/login_check.php` (line 2)
- `sign/save_signup.php` (line ~95)

### Enable HTTPS Cookies

In `session_set_cookie_params()`, change:
```php
'secure' => false,  // Change to true for HTTPS
```

### Add More User Fields

1. Add columns to `user_data.csv` header
2. Modify `save_signup.php` to save new fields
3. Update `login_check.php` to retrieve new fields
4. Store in `$_SESSION` in `check_session.php`
5. Access in your pages via `$_SESSION['field_name']`

## 🚨 TROUBLESHOOTING

### Issue: User not staying logged in
**Solution**: 
- Check if cookies are enabled in browser
- Clear browser cache and try again
- Verify cookie settings in `check_session.php`

### Issue: API returning 401
**Solution**:
- Login first, then try API call
- Cookies might be cleared
- Check `debug_profile.php` for session status

### Issue: User data not displaying
**Solution**:
- Verify user_data.csv contains the user
- Check CSV formatting (no extra spaces)
- Use `debug_profile.php` to inspect

### Issue: Logout not working
**Solution**:
- Try clearing cookies manually
- Check `check_session.php?logout=true` URL
- Verify PHPSESSID cookie is set
